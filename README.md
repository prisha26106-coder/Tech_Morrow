# TechMorrow — Beginner-friendly e-waste website

## How to run
1. Extract the ZIP file.
2. Open the `TechMorrow` folder in VS Code.
3. Open `index.html` in a web browser.
4. Use the top navigation bar to move between pages.

## Files
- `index.html` — home page. The main content has no page-navigation links; use the top navigation bar.
- `what-is-ewaste.html` — what e-waste means.
- `history.html` — history and global statistics.
- `environmental-impact.html` — environmental effects.
- `causes-of-ewaste.html` — causes of e-waste.
- `solutions.html` — device dropdown and recommendations.
- `recycle.html` — recycling and safety steps.
- `quiz.html` — interactive quiz.
- `pledge.html` — pledge checklist and response.
- `resources.html` — further reading.
- `estimator.html` — rough device value estimator.
- `styles.css` — shared CSS with beginner-friendly comments.
- `script.js` — small interactions for the dropdown, quiz, pledge and estimator.

Images load from Unsplash, so an internet connection is needed to see them. The value estimator provides an illustrative guide, not a live market quote.


## New homepage features

- The Google Translate selector is in the homepage header. It offers English, Hindi, Telugu, Punjabi and Tamil. It needs an internet connection.
- The map search asks for a city, area or PIN code, then embeds a Google Maps search for e-waste donation/recycling centres. No API key is needed. The results come from Google Maps, so users should verify details and call centres before visiting.
